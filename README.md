# CareerPilot AI

AI-powered career and job intelligence platform built with Java and Spring Boot.

## Planned features
- User accounts with JWT authentication
- Resume upload and PDF parsing
- Job search through an external Jobs API
- AI resume-to-job matching, with missing skills and cover letters

## Tech stack
Java 17, Spring Boot 4, Spring Data JPA, H2 (PostgreSQL planned), Maven

## Run locally
`.\mvnw.cmd spring-boot:run`, then open http://localhost:8081/

## Status
Phase 1 done: project setup and User API.
